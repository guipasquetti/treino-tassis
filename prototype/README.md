# treino-tassis — protótipo original

Este é o conteúdo original do repositório `guipasquetti/treino-tassis` antes de virar o
projeto Expo (`App Treino`, ver [`../HANDOFF.md`](../HANDOFF.md)). É um app de página
única em HTML/JS puro, conectado direto ao mesmo projeto Supabase (`treino-tassis`,
`fshwcaxcbnudvoyyqaxy`) via `@supabase/supabase-js` por CDN.

Preservado aqui (histórico git original substituído em 02/set/2026) porque é **protótipo
funcional em uso real** — não só mockup: cobre login/cadastro, fluxo de convite +
anamnese, execução de treino com histórico de cargas por exercício (cores por grupo:
push/pull/legs/plan), montagem de dieta com busca na tabela TACO e lista de refeições.

Usar como referência de lógica de negócio e UX ao construir as telas equivalentes no app
Expo — várias decisões de produto já estão implementadas aqui, mesmo que informalmente.
